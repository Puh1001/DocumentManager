## Purpose
Explore recent code changes and write journal entries documenting progress, decisions, and learnings.

## Skills Activation
- **MUST READ**: `../../.cursor/skills/document-skills/`

## Workflow
1. Review recent git commits and changes.
2. Identify key decisions, challenges, and solutions.
3. Write concise journal entries documenting:
   - What was accomplished
   - Key learnings
   - Decisions made and rationale
   - Questions or blockers
4. Save entries in a structured format.

**IMPORTANT:** Keep entries concise and actionable.
