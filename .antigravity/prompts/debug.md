## Purpose

Debug and analyze issues using the `debugger` agent.

## Variables

ISSUE: $ARGUMENTS

## Workflow:

1. **Understand the Issue**
   - Reproduce the issue when possible
   - Gather error logs and stack traces
   - Identify the scope and impact

2. **Investigate Root Cause**
   - Use the "5 Whys" technique
   - Trace execution path to find failure point
   - Check for recent changes that might have caused the issue
   - Use `sequential-thinking` and `debugging` skills

3. **Propose Solution**
   - Develop clear, actionable fixes
   - Consider side effects and regression risks
   - Suggest preventive measures

4. **Report**
   - Problem Summary
   - Root Cause
   - Evidence (logs, traces)
   - Recommended Fix
   - Prevention measures

**IMPORTANT:** Sacrifice grammar for the sake of concision when writing reports.
